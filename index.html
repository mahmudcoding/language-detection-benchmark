Method and limits

Accuracy. Unrestricted top-1 language recognition, with Uzbek’s two scripts reported separately. Standard, informal, noisy and short texts share related sentences. Labels were authored for the benchmark and have not had independent native-speaker review. The corpus was reused as candidates were added. No model was trained or fine-tuned for this test. The 27 mixed or ambiguous diagnostic inputs are excluded from scores.

CPU and memory. Apple M3, 16 GiB RAM; CPU only. Each model ran in a fresh process, warmed on all 280 texts, then measured for 20 passes (3 for PyTorch models). PyTorch and BLAS used one thread; native engines used their defaults. Median latency includes preprocessing, tokenization and top-1 output, and excludes model loading. RAM is the warmed process’s resident memory in decimal MB, including its runtime; it is not a minimum server requirement or a power measurement. Runtime differences and a single machine limit generalization.

Settings. Cleanup normalizes Unicode, apostrophes and whitespace, removes URLs, handles, hashtags and invisible formatting controls, and does no transliteration. OpenLID uses its author’s preprocessing. CLD2 uses bestEffort=True, which favors guesses; unsupported-language rejection was not evaluated. NbAiLab uses the quantized 159-language .ftz model. Spellman uses a Python/NumPy reference; its numbers do not represent native Rust speed. CLD3 uses cld3-asm 4.0.0; Franc uses 6.2.0; MediaPipe uses 1.0.1 with the float32 v1 detector. Transformer runs use float32; Polyglot Tagger pools token scores by language.

Verification. All 18 models were measured on the CPU, and their 5,040 warmup top-1 predictions matched the previously saved selected configurations. Model names link to their sources; model checkpoints are pinned where available.

Measured locally on 10 September 2026. Lower latency and RAM are better; higher accuracy is better.
